# Publish and present

The `Publish Little Sorters` workflow deploys `web/` to GitHub Pages. Once, open repository **Settings → Pages**, select **GitHub Actions** as Source, and save. Then rerun the workflow under **Actions → Publish Little Sorters → Run workflow** if its initial run happened before Pages was enabled.

Expected address: https://jinxiao-wan.github.io/Raspberry-Pi-Children-s-Garbage-Sorting-Learning-System/

To demonstrate the project in about one minute:

1. Start a game and classify an object. Point out the score and explanation.
2. Search `banana` or `香蕉皮` and show the category.
3. Open Photo lab, run the paper-cup example and choose `纸杯`.
4. Open Project story and show the original mini-program screenshots and limitations.

Switch the language button to present in Chinese. Supporting browsers offer installation; on other browsers, use a bookmark or Add to Home Screen if available.

The validation workflow exports desktop/mobile images and three recognition-process frames as the `app-previews` artifact. Those captures show the reconstructed app, while `web/assets/` contains original evidence.
